# Void Full Stack

เว็บไซต์แนะนำตัวและรวบรวมผลงานของ **ชัยวัฒน์ รุจิเมธาภาส (เคน)**  
Freelance Full Stack Developer และ IT Support

> เขียนได้ทุกภาษา แต่จำโค้ดไม่ได้เลย

## เกี่ยวกับเว็บไซต์

เว็บไซต์แนว Programmer / Minimal สำหรับนำเสนอ:

- งานพัฒนาเว็บไซต์และระบบเฉพาะทาง
- การเชื่อมต่อ API ฐานข้อมูล อุปกรณ์ และระบบภายนอก
- การรับช่วงแก้ไขและต่อยอดโค้ดเดิม
- งาน Server, Virtualization และ Database Backup
- งาน IT Support, Network, VPN และ Remote Desktop
- การทดลอง Local AI บนอุปกรณ์ Android

เว็บไซต์สร้างด้วย HTML, CSS และ JavaScript โดยใช้ AI ช่วยพัฒนา และเผยแพร่ผ่าน GitHub Pages

## เทคโนโลยี

- HTML5
- CSS3
- JavaScript
- GitHub Pages
