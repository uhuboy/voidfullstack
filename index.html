01 / ABOUT VOID

พื้นที่ที่เริ่มจากศูนย์ แล้วค่อย ๆ ทำจนเป็น

Void Full Stack คือพื้นที่ทำงาน ทดลอง และแบ่งปันความรู้ด้านไอที เน้นการนำเทคโนโลยีมาแก้ปัญหาจริง เป็นคนเรียนรู้เร็ว ถนัดด้านซอฟต์แวร์และการเชื่อมต่อระบบหลายรูปแบบ รวมถึงสามารถศึกษาและรับช่วงแก้ไขโค้ดที่พัฒนาโดยโปรแกรมเมอร์คนเดิมได้ โดยไม่ยึดติดว่าทุกงานต้องเริ่มเขียนใหม่ตั้งแต่ศูนย์

  • เรียนรู้เครื่องมือและระบบใหม่ได้รวดเร็ว
  • วิเคราะห์โค้ดเดิมและโครงสร้างฐานข้อมูล
  • แก้ไขข้อผิดพลาดและเพิ่มความสามารถให้ระบบเดิม
  • เชื่อมต่อเว็บไซต์ API ฐานข้อมูล และระบบภายนอก
  • เลือกเครื่องมือให้เหมาะกับงานและงบประมาณ

02 / SELECTED WORK

ระบบที่เคยลงมือทำ

ผลงานส่วนใหญ่เป็นระบบที่พัฒนาตามความต้องการของลูกค้าแต่ละราย ตั้งแต่เว็บไซต์บริษัท แอปพลิเคชัน ไปจนถึงระบบที่เชื่อมต่อฐานข้อมูล อุปกรณ์ เซิร์ฟเวอร์ และบริการคลาวด์

ⓘ

หมายเหตุ: ผลงานเป็นงานรับจ้างพัฒนาตามโจทย์ของลูกค้า ไม่ใช่ซอฟต์แวร์สำเร็จรูปที่เปิดขายทั่วไป

01

เว็บไซต์บริษัทและร้านค้า

พัฒนาเว็บไซต์สำหรับสำนักงานบัญชี บริษัทต่อเติมและตกแต่งบ้านหรือสำนักงาน ธุรกิจพัดลมไอเย็น อุปกรณ์เลี้ยงปลาสวยงาม และธุรกิจเสื้อผ้า โดยเน้นข้อมูลอ่านง่าย รองรับมือถือ และดูแลต่อได้สะดวก

  • Corporate Website
  • Responsive
  • CMS
02

ระบบจองห้องประชุม

จัดการตารางจองห้อง ตรวจสอบช่วงเวลาว่าง ออกใบเสนอราคาและใบเสร็จ พร้อมบันทึกข้อมูลการชำระเงิน เพื่อช่วยลดขั้นตอนงานเอกสารและข้อมูลซ้ำซ้อน

  • Booking
  • Quotation
  • Receipt
  • Payment
03

ระบบเคส เคลม และงานซ่อม

บันทึกและติดตามสถานะเคส ตรวจสอบประวัติการเคลม จัดทำใบเสนอราคาซ่อม และช่วยให้ทีมงานค้นหาข้อมูลย้อนหลังได้จากจุดเดียว

  • Case Tracking
  • Claim
  • Repair
  • Quotation
04

ระบบอ่านป้ายทะเบียนรถ

อ่านข้อมูลป้ายทะเบียนจากวิดีโอที่บันทึกไว้ ประมวลผลผ่านบริการคลาวด์ และจัดเก็บรูปภาพ เลขทะเบียน รวมถึงข้อมูลที่เกี่ยวข้องลงฐานข้อมูลสำหรับค้นหาในภายหลัง

  • Computer Vision
  • Cloud API
  • Video Processing
  • Database
05

ระบบติดตามอุปกรณ์ด้วย Beacon

รับข้อมูลจากอุปกรณ์ Beacon ผ่าน MQTT และแสดงผลบนแดชบอร์ด รองรับ MAC Address, RSSI, Battery และ Timestamp พร้อมแสดงข้อมูลตำแหน่งบนแผนผังสำนักงาน

  • Beacon
  • MQTT
  • Dashboard
  • Floor Plan
06

ระบบเฉพาะทางตามกระบวนการทำงาน

วิเคราะห์ปัญหาเดิมขององค์กร แล้วออกแบบระบบให้สอดคล้องกับขั้นตอนทำงานจริง เน้นลดงานซ้ำ ลดความผิดพลาด และทำให้ข้อมูลที่กระจัดกระจายกลับมาใช้งานร่วมกันได้

  • Custom Software
  • Automation
  • Integration
07

Virtualization และระบบสำรองฐานข้อมูล

ติดตั้งและจัดการระบบ Virtualization ด้วย Hyper-V และ VMware Workstation สำหรับแยกสภาพแวดล้อมของเซิร์ฟเวอร์ ระบบทดสอบ และโปรแกรมที่มีความต้องการแตกต่างกัน

เขียนสคริปต์สำหรับสำรองฐานข้อมูลตามเวลาที่กำหนด จัดเก็บไฟล์สำรอง และส่งไฟล์ขึ้นพื้นที่ Cloud Storage เพื่อช่วยลดความเสี่ยงเมื่อเครื่องหลักหรือระบบฐานข้อมูลมีปัญหา

  • Hyper-V
  • VMware Workstation
  • Virtual Machine
  • Backup Script
  • Cloud Storage
08

แอป Android คำนวณตัวเลขจากวันเกิด

พัฒนาแอปพลิเคชัน Android สำหรับคำนวณตัวเลขจากวัน เดือน และปีเกิด แล้วนำผลลัพธ์ไปแสดงเป็นข้อมูลตามเงื่อนไข สูตร และชุดข้อความที่กำหนดไว้

ระบบครอบคลุมตั้งแต่การรับข้อมูลและตรวจสอบวันที่ การประมวลผลตามสูตร การเลือกชุดข้อมูลผลลัพธ์ ไปจนถึงการออกแบบหน้าจอให้ใช้งานบนโทรศัพท์ได้สะดวก

  • Android Application
  • Date Calculation
  • Business Logic
  • Mobile UI

  • 03. ประมวลผลข้อมูลภายในอุปกรณ์
