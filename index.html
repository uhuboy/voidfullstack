02 / SELECTED WORK

ระบบที่เคยลงมือทำ

ผลงานส่วนใหญ่เป็นระบบที่พัฒนาตามความต้องการของลูกค้าแต่ละราย ตั้งแต่เว็บไซต์บริษัทไปจนถึงระบบที่เชื่อมต่ออุปกรณ์และบริการคลาวด์

ⓘ

หมายเหตุ: งานทั้งหมดเป็นงานรับจ้างพัฒนาตามโจทย์ ไม่ใช่ซอฟต์แวร์สำเร็จรูปที่เปิดขายทั่วไป

01

เว็บไซต์บริษัทและร้านค้า

พัฒนาเว็บไซต์สำหรับสำนักงานบัญชี บริษัทต่อเติมและตกแต่งบ้านหรือสำนักงาน ธุรกิจพัดลมไอเย็น อุปกรณ์เลี้ยงปลาสวยงาม และธุรกิจเสื้อผ้า โดยเน้นข้อมูลอ่านง่าย รองรับมือถือ และดูแลต่อได้สะดวก

  • Corporate Website
  • Responsive
  • CMS
02

ระบบจองห้องประชุม

จัดการตารางจองห้อง ตรวจสอบช่วงเวลาว่าง ออกใบเสนอราคาและใบเสร็จ พร้อมบันทึกข้อมูลการชำระเงิน เพื่อช่วยลดขั้นตอนงานเอกสารและข้อมูลซ้ำซ้อน

  • Booking
  • Quotation
  • Payment
03

ระบบเคส เคลม และงานซ่อม

บันทึกและติดตามสถานะเคส ตรวจสอบประวัติการเคลม จัดทำใบเสนอราคาซ่อม และช่วยให้ทีมงานค้นหาข้อมูลย้อนหลังได้จากจุดเดียว

  • Case Tracking
  • Claim
  • Repair
04

ระบบอ่านป้ายทะเบียนรถ

อ่านข้อมูลป้ายทะเบียนจากวิดีโอที่บันทึกไว้ ประมวลผลผ่านบริการคลาวด์ และจัดเก็บรูปภาพ เลขทะเบียน รวมถึงข้อมูลที่เกี่ยวข้องลงฐานข้อมูลสำหรับค้นหาในภายหลัง

  • Computer Vision
  • Cloud API
  • Database
05

ระบบติดตามอุปกรณ์ด้วย Beacon

รับข้อมูลจากอุปกรณ์ Beacon ผ่าน MQTT และแสดงผลบนแดชบอร์ด รองรับ MAC Address, RSSI, Battery และ Timestamp พร้อมระบุตำแหน่งข้อมูลบนแผนผังสำนักงาน

  • Beacon
  • MQTT
  • Dashboard
  • Floor Plan
06

ระบบเฉพาะทางตามกระบวนการทำงาน

วิเคราะห์ปัญหาเดิมขององค์กรแล้วออกแบบระบบให้สอดคล้องกับขั้นตอนทำงานจริง เน้นลดงานซ้ำ ลดความผิดพลาด และทำให้ข้อมูลที่กระจัดกระจายกลับมาใช้งานร่วมกันได้

  • Custom Software
  • Automation
  • Integration

06 / VOID LAB

เปลี่ยนมือถือเรือธงตกรุ่นให้เป็น AI ขนาดพกพา

งานอดิเรกที่กำลังทดลองคือการนำฮาร์ดแวร์เก่าที่ยังมีประสิทธิภาพ กลับมาใช้ประโยชน์ ลดการพึ่งพาบริการคลาวด์ และเปิดโอกาสให้สร้างระบบ AI ที่ทำงานภายในอุปกรณ์ได้

VOID LOCAL AI device: fold-series ram: 12 GB compute: snapdragon 8 runtime: llama.cpp / mnn-llm ● model running locally

// EXPERIMENTAL PROJECT

Local AI ที่ไม่ต้องส่งข้อมูลทุกอย่างขึ้นคลาวด์

ทดลองใช้ Samsung Z Fold 2 และ Z Fold 5 ซึ่งมี RAM 12GB และชิป Snapdragon 8 Series เพื่อรันโมเดลภาษาภายในเครื่อง ผ่าน Llama.cpp หรือ MNN-LLM รวมถึงปรับแต่งโมเดลให้เหมาะกับอุปกรณ์

เป้าหมายคือการต่อยอดไปสู่โปรเจกต์ AI ที่ประหยัดค่าใช้บริการ ใช้งานแบบออฟไลน์ได้ และช่วยเพิ่มความเป็นส่วนตัวของข้อมูล เช่น โปรแกรมสแกนและอ่านข้อความจากใบเสร็จสำหรับใช้งานฟรี

  • 01. ใช้ฮาร์ดแวร์เดิมให้เกิดประโยชน์สูงสุด
  • 02. ลดค่าใช้จ่ายบริการ AI ภายนอก
  • 03. ประมวลผลข้อมูลภายในอุปกรณ์
  • 04. ทดลองก่อน แล้วค่อยพัฒนาเป็นของที่ใช้ได้จริง
